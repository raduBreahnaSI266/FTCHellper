# Setup

See the root README for exact local start commands. The intended local workflow uses Python 3.12+, Node.js 20.9+, npm, and SQLite. This session runs the API at `127.0.0.1:8001` and frontend at `127.0.0.1:3001` to avoid stale listeners on the default ports. A PostgreSQL URL can be supplied through `DATABASE_URL` when ready, but Supabase authentication, row-level policies, and private object storage are not yet implemented.

The backend applies the schema with `alembic upgrade head`. API docs are generated by FastAPI at `/docs`. MP4 uploads up to 500 MB are saved under `backend/local-videos/`, with metadata/results in local SQLite. Click **Analizează video** to measure duration, resolution, FPS, decoded frames, and approximately one frame per second. Robot detection is currently unavailable; the video is left for manual review. The event timeline is API-backed and synchronized with playback. Keep both servers bound to `127.0.0.1` because authentication and authorization are not implemented.
